## Overview

Kashida Slider provides a visual editor and a slider library for building responsive sliders and carousels directly in WordPress. Configure layouts, typography, colors, navigation, and device-specific previews without adding external JavaScript libraries.

![Kashida Slider feature overview](kashida-slider-screens/Kashida%20Slider%20Feature%20Showcase.png)

## Features

### Create sliders from custom or dynamic content

Choose between Custom Slider, Dynamic Content Slider, and Carousel Slider. Dynamic sources can display content from your blog, WooCommerce products, or portfolio projects.

![Dynamic content slider](kashida-slider-screens/Dynamic%20Content%20Slider%20Feature%20Banner.png)

### Responsive carousel layouts

Set the number of visible items for desktop, tablet, and mobile. Use navigation arrows, pagination dots, touch swipe, and optional autoplay.

![Carousel slider features](kashida-slider-screens/Carousel%20Slider%20Feature%20Showcase.png)

### Flexible slider presentation

Adjust slider appearance with layout presets, typography, colors, overlays, image settings, and transition effects. Preview the design for desktop, tablet, and mobile in the editor.

![Main slider features](kashida-slider-screens/Main%20Slider%20Feature%20Showcase.png)

### Responsive and modern design

Build a presentation that adapts to different screen sizes while keeping the editor workflow inside WordPress.

![Responsive slider showcase](kashida-slider-screens/Modern%20Responsive%20Slider%20Plugin%20Showcase.png)

## Installation

1. Download the plugin ZIP from the [Releases](https://github.com/mrwan-bg/kashida-slider/releases) page.
2. In WordPress, go to **Plugins → Add New Plugin → Upload Plugin**.
3. Upload the ZIP file and activate **Kashida Slider**.
4. Open **Kashida Slider** in the admin menu and create a slider.
5. Copy the generated shortcode and paste it into a page, post, or supported page-builder text block.

## Shortcode

Use the shortcode generated by the plugin. The format is:

`[kashida_slider id="123"]`

Replace `123` with the ID of your slider.

## Requirements

- WordPress 6.0 or later
- PHP 7.4 or later
- WooCommerce is needed only when using WooCommerce as a content source.

## Compatibility and localization

- Responsive layouts and RTL support.
- Translation-ready with the `kashida-slider` text domain.
- Includes a partial Arabic translation.
- No external front-end libraries; front-end assets load on pages using the shortcode.
